One pipeline, four lectures

mini |>
  mutate(
    bed_ok = str_detect(bedtime, regex("\\d|midnight", ignore_case = TRUE)),
    sleep_group = case_when(
      sleep_hours < 6    ~ "Short",
      sleep_hours <= 7.5 ~ "Normal",
      sleep_hours > 7.5  ~ "Long"
    )
  ) |>
  left_join(menu, by = "drink") |>
  group_by(program) |>
  summarize(
    n = n(),
    n_readable = sum(bed_ok, na.rm = TRUE),
    mean_sleep = mean(sleep_hours, na.rm = TRUE),
    n_short = sum(sleep_group == "Short", na.rm = TRUE),
    mean_caffeine = mean(caffeine_mg, na.rm = TRUE)
  )

TipWhere each lecture shows up
  • str_detect(): "idk" is FALSE, the blank is NA, and na.rm = TRUE leaves both out of the count
  • case_when(): the NA sleep stays NA, so it is not counted as "Short"
  • left_join(): "Matcha" is not in menu, so its caffeine is NA
  • na.rm = TRUE changes the denominator: Business caffeine is (95 + 0) / 2

Silent failures

No error does not mean correct

WarningWhat is a silent failure?

Code that runs with no error and no warning, and still gives a wrong or empty answer. These are the questions that cost the most marks, because nothing tells you to look twice.

ImportantSomething that maybe you can do
  1. Count the rows before and after
  2. Count the NAs: sum(is.na(x))
  3. Look at a few rows, not just the summary
  4. Try it by hand on a tiny example
TipLoud errors are the friendly ones

separate_wider_delim() with uneven pieces, or n() outside summarize(), stop and tell you what is wrong. The next slides are about the ones that do not.
